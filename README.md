# EmbedVisOrderTool

## プロジェクト概要
**EmbedVisOrderTool** は、埋め込み視覚化を搭載した注文システムです。  
商品情報を埋め込みに変換し、2D/3D 空間に可視化することで、ユーザーが商品間の関係性を直感的に理解しながら注文できる仕組みを提供します。  
さらに埋め込みを活用したレコメンド機能を備え、ショッピング体験を強化します。  

---

## 全体アーキテクチャ設計手順

### 1. 要件定義
- ユーザーが商品を検索・選択・注文できる基本的な EC 機能  
- 商品情報をベクトル化し、2D/3D 可視化する機能  
- 埋め込みを活用した推薦機能（類似商品やパーソナライズ推薦）  
- 管理者が商品を追加・編集・削除できる管理画面  

### 2. バックエンド設計
- **フレームワーク**: Django + Django REST Framework (DRF)  
- **主な機能**
  - 商品カタログ管理 API (CRUD)  
  - 埋め込み生成 API (Hugging Face Transformers モデルを利用)  
  - 推薦 API (類似商品検索 / 個別推薦)  
  - 注文管理 API (カート・注文処理)  
  - ユーザー認証・認可 (JWT)  
- **ベクトル検索**: Milvus / Weaviate (大規模検索対応)  
- **RDB**: PostgreSQL (商品データ・注文履歴・ユーザー管理)  
- **キャッシュ**: Redis (検索結果キャッシュ、セッション管理)  
- **管理画面**: Django Admin を利用し、商品登録・編集を GUI で実現  

### 3. モデル設計
- Hugging Face Transformers ベースの埋め込みモデルを選定・ホスティング  
- 商品名・説明文・カテゴリーを入力にベクトル化  
- ベクトルDBに格納し、推薦・可視化に活用  

### 4. フロントエンド設計
- **フレームワーク**: Next.js + React  
- **主要機能**
  - 商品一覧・詳細表示  
  - 商品検索 (バックエンド API と連携)  
  - 埋め込み可視化ビュー  
    - react-three-fiber + three.js → 3D 空間での商品クラスタ表示  
    - Plotly.js → 2D/3D 散布図可視化  
  - カート・注文 UI  
  - レコメンド商品の表示  

### 5. インフラ設計
- **コンテナ**: Docker (バックエンド・フロントエンド・DB・ベクトルDB)  
- **オーケストレーション**: Docker Compose (小規模) → Kubernetes (拡張時)  
- **デプロイ**: AWS (EC2 + RDS + S3 + CloudFront) or GCP/Azure  
- **認証/認可**: JWT ベースのユーザー管理

   - 商品カタログ管理 API (Django ORM + DRF)
